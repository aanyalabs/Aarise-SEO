## STEP 1 — Create 6 Google Sites

Go to: sites.google.com
Sign in with the Aarise Google account.

For EACH site:
1. Click the big "+" button (Blank site)
2. Click "Untitled Site" at the top and set the site name (see each file below)

4. Click below the title and add a "Text box" — paste the full body content
5. Click "Publish" (top right) → set the web address (URL slug) as specified
6. Click Publish again to confirm
